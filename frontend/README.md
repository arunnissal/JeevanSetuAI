# JeevanSetu AI - Frontend Client

This directory contains the React Native/Expo frontend source code for the **JeevanSetu AI** health companion application.

For full project architecture, backend configuration, and product features, see the root-level [README.md](../README.md).

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env`:
   ```env
   EXPO_PUBLIC_API_URL=http://localhost:8000/api/v1
   EXPO_PUBLIC_ENV=development
   ```

3. Start the application:
   ```bash
   npx expo start --web
   ```
